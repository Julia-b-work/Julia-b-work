Computer engineering student at UFSCar. I build things with Python, C/C++, and
Rust — mostly where LLMs meet real software.

## Projects

- **[Emily](https://github.com/Julia-b-work/emily-language)** — a statically typed Lisp for configuration, built from scratch in Rust. Compiles to JSON, YAML, and TOML, with imports and error positions.
- **[pdf-chat](https://github.com/Julia-b-work/pdf-chat)** — a RAG web app (Streamlit + Claude) that answers questions about your PDFs with grounded, cited answers. [Live demo](https://pdf-chat-study-buddy.streamlit.app).
- **[discord-mimic](https://github.com/Julia-b-work/discord-mimic)** — a Discord bot that learns a user's writing style with a Markov chain and answers in their voice via Claude.
- **[Wendy](https://github.com/Julia-b-work/wendy-agent)** — a codebase Q&A agent and MCP server: 10 tools for semantic code search, tree-sitter symbol lookup, and git history.
